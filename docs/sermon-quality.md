# Sermon presentation quality

The generator preserves the pastor's Second Scripture Lesson reference and retrieves every requested verse in NIV independently of the editorial model. Supporting passages also use sourced NIV text. BibleGateway chapter markup is parsed by translation and verse number; missing text or unavailable sources stop generation rather than silently dropping verses or using model wording. Older saved presentations are repaired on download. Source references are retained in scripture slide notes.

Text uses measured Calibri Bold glyph advances, explicit line breaks, fixed margins and a height budget. It does not rely on PowerPoint's edit-time shrink setting. The export path runs before image generation to catch impossible layouts. The reference template's background, white scripture text and yellow sermon text remain in place.

Images default to `gpt-image-2.5-sunburst`, xhigh quality, 1536×864. `OPENAI_SERMON_IMAGE_MODEL` can explicitly override the model; an override must support those image options. Prompting and both visual reviews require a single coherent scene, readable lighting and natural color. Collages and muddy/dark scenes are rejected. A pass requires a numeric score from 90 to 100, an explicit boolean pass and no reported defects. Monthly image reuse requires style version 6 and the matching model. Exhausted credits and missing model access produce actionable errors; rejected artwork is never silently replaced with a background.

Official model reference: https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst
